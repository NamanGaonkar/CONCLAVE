# Conclave v0.5.0

**A local network of Claude Code, Antigravity, Codex, Gemini, Cursor, Grok & Copilot agents that run themselves.**
Autonomous multi-agent orchestration, messaging, routing, and memory graph, running completely local-first and offline on your machine.

---

## What's new in Conclave v0.5.0

- **Branch Metro View:** Replaced the pixel-office visual canvas with an interactive vector SVG subway map. Each agent is a colored line, each task is a station, merges are junctions, and redirects are track switches with direction indicators.
- **Glowing Animated Trains:** Working agents feature animated glowing transit trains moving dynamically along their routes.
- **Junction Conflict Signals:** Merge conflicts and blocked tasks display a pulsing red railway signal light.
- **Direct Task Inspection:** Clicking any station node directly opens that task's chat/terminal and inspects git changes.
- **Ember Dark Theme:** Complete UI overhaul to a warm Ember Dark theme (`#0C0A07`, `#14110C`, `#1B1710`, `#2A2417`, `#F5AF28`, `#FFD15C`, `#F5EDD8`).
- **Lato Typography:** Clean, modern, highly legible typography powered by bundled local Lato fonts.
- **Vocabulary Modernization:** Renamed "Boss" to "Lead", "workers" to "agents", and "Hive" to "Conclave".
- **Enhanced Auto-Updater:** Seamless update checking against `NamanGaonkar/CONCLAVE` ensuring immediate update notifications for installed users.
