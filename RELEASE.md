# Conclave v0.5.2

**A local virtual office of Claude Code, Antigravity, Codex, Gemini, Cursor, Grok & Copilot agents that run themselves.**
Autonomous multi-agent orchestration, messaging, routing, and memory graph, running completely local-first and offline on your machine.

---

## What's new in Conclave v0.5.2

- **Darker Golden Yellow Light Theme:** Deepened light mode background to a rich, warm golden yellow (`#E5BE53`) with `#F2D376` elevated panels and high-contrast espresso ink (`#1C1405`).
- **Smooth Lato & Inter Typography:** Completely removed jagged, pixelated "Press Start 2P" fonts from UI headers, cards, and modal dialogs in favor of smooth, antialiased Lato and Inter typography.
- **Symmetrical & Balanced Panels:** Fixed uneven box margins, unbalanced line heights, and asymmetric padding across all panels, adding clean 6px rounded corners and smooth depth shadows.
- **Interactive Office Floor Restored:** Full pixel office floor with agent desks, monitors, coffee breaks, and ambient animations running smoothly.
- **Cleaned Settings & Custom Branding:** Removed all Pro paywalls, discount banners, and external Discord links; wired GitHub star button directly to `NamanGaonkar/CONCLAVE`.
- **Fixed GitHub Actions Release Builds:** Synchronized package manifest and lockfile, adding resilient installation fallbacks so CI and release builds run reliably.
